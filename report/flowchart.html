mergeSort(lo, hi) entrysort the half-open range A[lo, hi)
hi − lo ≤ 1 ? ── yes ──▶ return 0 or 1 element: already sorted, this is the base case of the recursion
mid ← ⌊(lo + hi) / 2⌋ split into two halves of ⌊n/2⌋ and ⌈n/2⌉ — the split needs no comparisons
mergeSort(lo, mid)
mergeSort(mid, hi)
merge(lo, mid, hi)both halves are now sorted; walk the two runs and write the smaller head first
while i < mid and j < hi:
  if A[i].key ≤ A[j].key → take i
  else → take jone comparison per element written; “≤” is what makes the sort stable
copy any remaining tail, write the buffer back into A[lo, hi), returnthe merge pass touches every element exactly once → Θ(k) work for a subproblem of size k

Recursion depth is ⌈log₂ n⌉ and every level of the tree touches all n elements exactly once, so the total work is c·n per level × (log₂ n + 1) levels = Θ(n log n). The iterative “while” loop above is the only place comparisons happen.
